# Gateway 部署资产边界

本目录保存 `vireon-gateway` 自身的验证和运行治理入口，后续按实际需要增加镜像和部署资产。
Platform、QBC、数据库、Redis、Nacos Server 或跨项目组合编排不归本目录所有。

部署资产必须：

- 对镜像和外部依赖使用精确版本或摘要，不使用 `latest` 或浮动标签；
- 将敏感值作为环境变量或 SecretResolver 引用注入，不提交真实凭据；
- 为 Gateway 配置独立端口、健康检查、资源限制、日志和回滚入口；
- 明确选择静态路由或 Nacos 路由作为单一事实源，并验证两种模式的外部路径等价；
- 只为真实存在且通过健康与契约验证的下游服务启用路由。

当前入口：`verify.ps1`运行本仓格式检查、测试及独立JAR验收，`check-docs.ps1`检查本地文档链接和空白。
`verify.ps1`自动生成当轮JSON回执；`deliver.ps1`从冻结源码在仓库外双构建并核对JAR摘要；
`test-delivery.ps1`仅运行回执脚本的合成反例回归。三个入口都保留证据，不清理目录或缓存。
使用方法见 [运行说明](../docs/runtime.md)。当前无镜像构建或发布部署脚本，不创建占位资产。
