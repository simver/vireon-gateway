# ADR-0003：先完成 Gateway 自身开发与独立验收

- 日期：2026-09-10；所有者：Gateway；状态：按用户明确范围调整记录，未提交、未实施。
- 用户决定：先不联合其他项目验证，先做好 Gateway 本身的开发。
- 本决策调整 [ADR-0002](ADR-0002-staged-gateway-delivery.md) 的首批验收前置条件，保留
  [ADR-0001](ADR-0001-gateway-boundary.md) 的独立边界、精确路径和真实服务激活规则。

## 决策

1. 首批仅交付 Gateway 自身独立构建、运行、静态路由机制、HTTP/Cookie透传、超时、错误、代理头防护与管理面隔离。
2. 自动化测试由本仓测试范围内的临时 HTTP 下游提供可控响应，用于观察路径、头、正文、故障和资源释放。
   测试替身不包含账号、数据库或IAM状态机，不作为业务服务发布；仅在测试配置启用，默认运行配置不指向测试替身。
3. 默认不激活未经真实接入验证的 IAM/Audit 路由；System/QBC 继续404。路由机制测试与真实服务接入状态分别报告。
4. 本期不启动、构建或修改IAM/Audit/QBC，不准备其数据库、账号或前端，不要求真实登录、改密、刷新、退出、
   权限、CSRF或浏览器联合验收。既有公共合同仅用于避免破坏传输语义，不由Gateway重做业务认证。
5. 真实服务接入与浏览器完整会话另设后续批次；共享HTTPS、域名证书、真实代理信任链和生产部署也不作为本期门禁。
   本仓使用隔离本机动态端口验证自身，不把它解释为用户选择了未来共享联调环境。
6. 本期完成状态为“Gateway自身开发与独立验收通过”；不能据此宣称真实服务已接入、前端会话通过或生产可用。

## 影响与回滚

PLAN-0001持续承接调整，历史ADR结论保留并标明本决策。无源码、数据库或运行配置迁移。
后续恢复联合验收时冻结实际服务制品、入口及合同，另列真实浏览器门禁；不得用本期测试替身结果替代。
本轮仅调整规划文档，不创建Goal或开始实现。Mix共同路线仍由原所有者维护；本轮未修改Mix，其旧联合验收范围
不作为本仓首批前置，跨项目恢复接入前再同步共同路线。
