# Gateway 开发流程

日期：2026-09-09。适用本独立仓库；仓库边界和安全硬规则以 [AGENTS.md](../AGENTS.md) 为准。
借鉴 Vireon Mix 的核心开发流程、代理执行标准及 Platform 固定候选验收经验；不继承其测试通过结论，
不形成相邻仓库源码、构建或运行依赖。各批次实际实施和验收状态以PLAN-0001及后续所属计划为准。

## 1. 需求、计划与决策

1. 阅读工作树状态、README、相关 ADR、实际版本、源码和测试；区分用户需求、现场事实、建议与待决项。
2. 代理在 `docs/plans/PLAN-NNNN-主题.md` 维护一份计划，包含范围、来源、方案、批次、验收、执行记录。
   新编号先核对本仓索引；唯一登记人维护编号，不复用取消号。跨仓引用注明所有者。
3. 优先核验官方配置和扩展点。首次运行栈选择须比较支持周期、兼容性及正式依赖解析；不以编译成功证明支持。
   自定义机制须说明官方缺口、维护成本、反例和退出条件；不照搬 Servlet 机制到 Reactive 应用。
4. 高影响版本、安全、公开 HTTP 或部署决策先写 ADR。已接受的历史结论不静默改写；新决策说明兼容和回滚。
5. 可以自行查清的技术问题由代理闭环；真实范围和产品取舍交给用户。提出必须回答的问题后等待实际答复，
   不设置倒计时或默认答案。用户要求先规划时只推进文档及允许的只读调查。

计划状态分别记录：已落盘、待决项、实现准入、基线提交、实施进度、验收和交付。不得把其中一项替代另一项。
跨任务实施前按已有授权提交共同计划基线；无提交授权时记录待提交范围。单任务不强制单独计划提交。

## 2. 执行和职责

- 开工前简述难点、风险、执行模式、Goal 建议、审查安排、依赖及停止边界。推荐模型不代表实际切换。
- 默认主代理负责闭环；重要安全设计与最终实现安排未参与该范围实现的独立审查者。子代理仅在当次授权
  或适用规则允许时派发，任务限定范围；不为占满并发拆分强耦合实现。
- Goal 只在用户明确要求创建后启用；未明确预算不设置额度。目标包含可观察完成条件、非目标及停止边界。
  不因长构建强制启用 Goal，不因预算耗尽宣称完成；状态操作遵循运行时工具规则。
- 已授权范围内按可验收批次持续实现、验证和返修，不逐阶段重复审批。假设失效返回设计，不削弱安全检查。
- Gateway 拥有自己的源码、配置、验证和文档。下游合同修改交由所属项目单独处理，不夹带 IAM/Audit 业务修复。
- 保留他人和既有未提交修改；分支和工作树先核对基线与用途。提交、合并、推送、发布、部署、删除分别遵循授权。

## 3. 分层验证

| 层次 | 证据要求 |
| --- | --- |
| 纯文档 | 差异、链接、状态和事实核对；不运行无关 Java 测试 |
| 受影响测试 | 从 HTTP 契约推导正例、拒绝和故障场景；测试下游可用于观察协议 |
| 完整门禁 | 本仓完整测试、格式、依赖和架构边界、路由契约、文档检查；实现时提供真实统一入口 |
| 独立构建 | 使用自身 Wrapper 和正式坐标，不依赖相邻源码或输出；涉及 Framework 从源码目录外的空缓存解析 |
| 自身运行 | 本仓测试下游+Gateway实际进程/JAR，验证协议、故障、安全；测试配置不混入默认活跃路由 |
| 真实组合（接入阶段适用） | 冻结 Gateway/IAM/Audit 提交和 JAR 摘要，使用隔离数据；真实浏览器验证 Cookie、CSRF、会话、读写与拒绝；ADR-0003确定本期后置 |
| 最终审查 | 记录发现、返修和复核；候选变化后重新验证受影响结论并完成适用交付门禁 |

本期测试替身足以承接Gateway自身协议验收；不得以其结果宣称真实会话通过。真实接入阶段不以所有写请求返回403证明CSRF正确，不以健康UP代替下游就绪，
不以旧候选回执或跳过测试的构建证明新候选验收。无变化且无未解风险时不重复运行相同检查。

## 4. 交付与证据

原计划集中记录命令、工作目录、候选标识、成功/失败/跳过、审查和未覆盖项；原始失败保留，不能只留最后绿色。
不得在日志、回执、截图或浏览器 trace 中保存凭据；敏感证据采集默认关闭或脱敏，扫描范围明确。
README 提供当前状态与入口，精确契约引用唯一来源；实际启动命令、端口和配置由实现验证后填写。

实际能力区分“文档规划”“测试通过”“本地浏览器联验”“共享环境联验”“生产发布”。本地 HTTP 不能证明生产 TLS。
基础版完成不代表 Nacos、镜像或部署完成。记录资源用途、精确 ID、日志及退出方式；退役严格遵循用户删除规则，
不自动清理目录、工作树、缓存、数据库或容器卷。用量仅记录可核验口径，缺项明示，不为补统计阻塞交付。
